## 3. 初版產生工具（`tools/bootstrap/`）

### 原文來源

`source/lunyu.chinese-poetry.json`：npm 套件 chinese-poetry 2.0.1 的論語（MIT 授權，20 篇 512 章，**簡體**，無英譯，分章同楊伯峻）。詳見 `source/SOURCE.md`。

### 工具

| 檔案 | 做什麼 |
|---|---|
| `convert_source.py` | 簡轉台灣繁體（OpenCC `s2tw`）。**先拿掉書名號**再轉，否則「《詩》云」會被轉成「詩雲」；引號改「」；異體字對照（目前只有「泛愛眾 → 汎愛眾」） |
| `zhuyin_font.py` | 從注音字型的字形「讀出」注音（字型本身沒存讀音文字）。驗證：README 的 12 個破音字全對；學而篇 548 字與校對過的拼音一致 |
| `make_drafts.py` | 原文 → 每章一個初版 YAML（`status: draft`），附 `check:` 清單列出需要人確認的破音字 |

### 用法

```bash
pip install pyyaml opencc fonttools freetype-py numpy pillow pypinyin
```

```bash
python tools/bootstrap/make_drafts.py --books 2
```

預設輸出到 `tools/bootstrap/drafts/`（不進 git、不影響網站）；確認無誤後加 `--out examples/v2` 放進正式資料。已存在的檔案不會被覆蓋（除非加 `--force`）。

### 產生器的規則與實測品質

| 步驟 | 規則 | 實測 |
|---|---|---|
| 原文 | 來源簡轉繁 | 與學而篇比對，字一致 98%，差異幾乎都是標點習慣 |
| 切說話者 | 句首或「。？！」』，；」後面的「X曰：」 | — |
| 分頁 | 說話者開新頁；句子結束且已有 2 個區塊就換頁；每頁最多 3 個區塊 | 學而篇 12/16 章與人工分頁相同 |
| 注音 | 字型預設讀音（台灣標準音）＋ 已校對章節的上下文讀音 | 學而 1.1–1.7 拼音正確率約 93%；錯的幾乎都是古文破音字（好 hào、與 yú、弟 tì…） |
| 拼音 | 一律由選定的注音轉出 | 注音與拼音一定一致 |
| 英文 | 只有「子曰：」先填 Confucius said,，其餘留空 | — |

### 試跑結果（19 篇全部產生，放在複本裡跑網站建置與 CI 檢查）

- 496 章、全書 1,654 頁；`check:` 清單共 3,320 處（平均每章約 7 個字要確認）
- `check_layout.js`：拼音對齊、文字壓到頁尾 **0 個錯誤**
- 唯一錯誤：**「鞟」「鼗」字型裡沒有**（顏淵篇、微子篇），投影片上會沒有注音、拼音為 `?`，要另外處理
- 精簡字型從約 100KB 變成約 700KB（1,377 個字）

## 4. 正式放進其他篇之前，必須先改的地方

1. **預先產生 PPT 的範圍**：`web/tools/export_all_pptx.js` 目前每章和每篇都預先產生，每章約 1MB。512 章加上整篇合輯約 1GB，會超過 GitHub Pages 單一網站 1GB 的上限。
   建議改成**只預先產生 `status: reviewed` 的章**，整篇合輯和未校對的章改在瀏覽器即時產生（網頁已經支援：清單裡沒有的就即時產生）。
2. **「鞟」「鼗」**：字型沒有這兩個字，`check_layout.js` 會擋下部署。要決定處理方式，例如改用異體字，或讓檢查對這兩個字放行。
3. 決定第 2 節的事項。

## 5. 已知的坑

| 坑 | 說明 |
|---|---|
| YAML 的 `no` | PyYAML 會把 `no` 當成布林值 False，所以 `books.yaml` 的篇號欄位叫 `num` |
| 異體字 | 爲、説、敎、衞、眞、卽、旣、緑 這些字形字型裡**沒有**；原文要用台灣標準字形 |
| 台灣讀音 vs 大陸讀音 | 拼音一律跟台灣標準音（與投影片上的注音一致），例如 賜 sì、辱 rù；現成的拼音工具（pypinyin）是大陸讀音，不要直接用 |
| pypinyin 會帶偏古文讀音 | 加了 pypinyin 的推測，正確率反而下降（例如把「其為人也」的為改成 wèi） |
| 雲端 session 的網路 | ctext.org、acmuller.net 等網站被擋；npm、PyPI 可以連。Playwright 在沒有設定語系的環境，中文檔名會變成 download（這是環境問題，不是網站的 bug） |
| 產生的檔案 | `web/data/*.json` 與精簡字型有放進 git（每次產生結果相同）；`web/pptx/`、`web/data/pptx.json`、`tools/bootstrap/drafts/` 不進 git |
